# English Phrases

Приложение для изучения английских фраз: 12 глав, всего 2566 фраз и выражений.
Vue 3 + Vite + TypeScript, данные в JSON, прогресс хранится в браузере.

**Открыть:** https://mirjalol9797.github.io/english-phrases/

## Установка на телефон

Приложение можно поставить как обычное — отдельной иконкой, без адресной строки
и с работой без интернета.

- **Android, Chrome:** открыть адрес выше, меню «три точки» → «Установить приложение».
- **iPhone, Safari:** открыть адрес, кнопка «Поделиться» → «На экран «Домой»».

Прогресс хранится в браузере устройства и между телефоном и компьютером не переносится.
Чтобы перенести, пригодится «Сохранить копию» в настройках.

## Запуск

Нужен Node.js 22.12 или новее (`node -v`) и yarn. Версия Node не формальность:
vitest 5 на более старой просто не ставится.

```bash
yarn install
yarn dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

| Команда | Что делает |
|---|---|
| `yarn dev` | Запуск для разработки с автообновлением |
| `yarn build` | Проверка типов и сборка в папку `dist` |
| `yarn preview` | Просмотр собранной версии |
| `yarn data:build` | Конвертация Word-файлов из `content/source` в JSON и проверка |
| `yarn data:validate` | Только проверка готовых JSON в `public/data` |
| `yarn test` | Тесты логики |
| `yarn test:watch` | Тесты с перезапуском при правках |
| `yarn pwa:check` | Проверка, что в офлайн-кэш собранной версии попало всё нужное |

## Как добавить новую главу

Word-файл кладётся в `content/source`, глава описывается в `content/chapters.config.json`
(имя файла, `id` для адреса, `order`), затем `yarn data:build`.
Поле `title` необязательно — без него название берётся из документа.

Поддерживаются два формата источника, он задаётся полем `format`.

### `format: "lessons"` — главы с фразами (по умолчанию)

Заголовки «N. English — Русский» (стиль «Заголовок 1») задают уроки, под каждым таблица
`ID | English phrase | Перевод`. Ровно 20 уроков по 10 фраз. У главы свой префикс ID
(`EE001` для Everyday English, `UE001` для Useful Expressions), нумерация сквозная: 001–200.
Префикс определяется автоматически по первой фразе.

### `format: "categories"` — главы с выражениями

Одна таблица на весь документ: `id | category | phrase_en | phrase_ru | example_en | example_ru`.
Каждая категория становится отдельным уроком, порядок уроков — порядок появления категорий.
Нумерация ID своя внутри категории (`GET001…`, `TAKE001…`), поэтому префикс главы указывается
в конфиге полем `prefix` (`CV` у English Core Verbs, `PR` у English Prepositions). В префиксе
допустимо подчёркивание — оно нужно составным категориям (`PRE_IN_FRONT_OF001`). Размер урока
и число уроков не фиксированы, пример употребления показывается под переводом. Так устроены
главы «English Core Verbs» и «English Prepositions».

### Проверка

Скрипт остановится и ничего не запишет, если найдёт ошибку: неверный формат или порядок ID,
повторяющийся ID, пустое поле, а для глав с фразами ещё и не 20 уроков или не 10 фраз в уроке.
Предупреждения (одинаковые переводы, повтор фраз между главами, урок короче пяти записей)
запись не блокируют.

## Прогресс

Хранится в `localStorage` этого браузера, на сервер ничего не уходит.

| Ключ | Что внутри |
|---|---|
| `english-phrases:progress` | коробка и срок повторения каждой фразы, дни занятий |
| `english-phrases:theme` | светлая, тёмная или как в системе |
| `english-phrases:speech` | включена ли автоозвучка карточек |
| `english-phrases:session-size` | сколько записей брать за одно занятие |
| `english-phrases:voice` | выбранный голос озвучки |
| `english-phrases:rate` | скорость речи |

Система Лейтнера: у фразы пять коробок с перерывами 1, 2, 5, 10 и 21 день. Коробка меняется
один раз за занятие, по итогу всех этапов фразы: все ответы верные — коробка выше, хоть одна
ошибка — обратно в первую. Фраза из последней коробки считается выученной.

Прогресс привязан к браузеру: очистка данных сайта или переход на другое устройство его сотрёт.
В настройках есть «Сохранить копию» и «Восстановить из файла».

## Офлайн и установка на телефон

Собранная версия — PWA: `vite-plugin-pwa` кладёт в кэш страницу, код, шрифты и все главы
(около 900 КБ), поэтому после первого открытия приложение работает без сети. Обновление
ставится само при следующем запуске.

Проверить, что в кэш попало всё нужное:

```bash
yarn build && yarn pwa:check
```

Установка на телефон: открыть сайт в браузере и выбрать «Установить приложение»
(Android) или «На экран «Домой»» (iOS, Safari).

## Тесты

Проверяется чистая логика: экраны и браузер не нужны, поэтому тесты идут за полсекунды.

```bash
yarn test
```

| Что проверяется | Где |
|---|---|
| Коробки и сроки Лейтнера | `src/utils/leitner.test.ts` |
| Даты, переход через месяц и год, местное время | `src/utils/date.test.ts` |
| Сравнение ответа: регистр, апостроф, знак в конце | `src/utils/answer.test.ts` |
| Сбор занятия, подбор вариантов, повтор ошибок | `src/utils/practice.test.ts` |
| Итог занятия по фразе | `src/utils/session.test.ts` |
| Поиск, подсветка, склонение | `src/utils/search.test.ts` |
| Прогресс, серия дней, копия и импорт | `src/stores/progress.test.ts` |
| Проверка данных глав | `scripts/lib/validate.test.mjs` |

Тесты писались от уже случившихся поломок: двух верных вариантов на экране,
неугадываемого ответа при одинаковом переводе и потери прогресса из-за одного поля.
Каждая из них ловится соответствующим тестом.

## Структура

```
content/
  source/                 Word-файлы глав (источник данных)
  chapters.config.json    порядок глав, id, формат источника, переопределение названий
scripts/
  docx-to-json.mjs        Word → JSON
  validate-data.mjs       проверка public/data
  lib/validate.mjs        общие правила проверки
public/data/
  chapters.json           список глав
  chapters/*.json         главы с уроками и фразами
src/
  types/                  типы данных
  services/               загрузка JSON
  stores/                 Pinia: контент, настройки, прогресс
  composables/            переиспользуемая логика
  components/             компоненты интерфейса
    practice/             карточка, четыре упражнения, кнопка озвучки
  views/                  экраны
  router/                 маршруты (hash-режим)
  styles/                 Tailwind и цвета светлой и тёмной темы
```

## Примечание

`yarn audit` показывает одно предупреждение в зависимостях `mammoth` (`sprintf-js`). Пакет
используется только локально в скрипте конвертации ваших Word-файлов и в приложение не попадает:
`yarn audit --groups dependencies` на зависимостях приложения не находит ничего.
