# English Phrases

Приложение для изучения английского: 12 глав фраз и выражений (2566 записей),
230 неправильных глаголов и словарь Oxford 3000 целиком — уровни A1, A2, B1 и B2,
3308 слов.
Vue 3 + Vite + TypeScript, данные в JSON, прогресс хранится в браузере.

**Открыть:** https://mirjalol9797.github.io/english-phrases/

## Установка на телефон

Приложение можно поставить как обычное — отдельной иконкой, без адресной строки
и с работой без интернета.

- **Android, Chrome:** открыть адрес выше, меню «три точки» → «Установить приложение».
- **iPhone, Safari:** открыть адрес, кнопка «Поделиться» → «На экран «Домой»».

Прогресс хранится в браузере устройства и между телефоном и компьютером не переносится.
Чтобы перенести, пригодится «Сохранить копию» в настройках.

## Запуск

Нужен Node.js 22.12 или новее (`node -v`) и yarn. Версия Node не формальность:
vitest 5 на более старой просто не ставится.

```bash
yarn install
yarn dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

| Команда | Что делает |
|---|---|
| `yarn dev` | Запуск для разработки с автообновлением |
| `yarn build` | Проверка типов и сборка в папку `dist` |
| `yarn preview` | Просмотр собранной версии |
| `yarn data:build` | Сборка JSON из источников в `content/source` и проверка |
| `yarn data:validate` | Только проверка готовых JSON в `public/data` |
| `yarn test` | Тесты логики |
| `yarn test:watch` | Тесты с перезапуском при правках |
| `yarn pwa:check` | Проверка, что в офлайн-кэш собранной версии попало всё нужное |

## Как добавить новую главу

Файл источника кладётся в `content/source`, глава описывается в `content/chapters.config.json`
(имя файла, `id` для адреса, `order`), затем `yarn data:build`.
Поле `title` необязательно для Word-файлов — без него название берётся из документа.
Поле `group` собирает несколько глав в раздел на главной (так сделаны уровни Oxford 3000).

Поддерживаются четыре формата источника, он задаётся полем `format`.

### `format: "lessons"` — главы с фразами (по умолчанию)

Заголовки «N. English — Русский» (стиль «Заголовок 1») задают уроки, под каждым таблица
`ID | English phrase | Перевод`. Ровно 20 уроков по 10 фраз. У главы свой префикс ID
(`EE001` для Everyday English, `UE001` для Useful Expressions), нумерация сквозная: 001–200.
Префикс определяется автоматически по первой фразе.

### `format: "categories"` — главы с выражениями

Одна таблица на весь документ: `id | category | phrase_en | phrase_ru | example_en | example_ru`.
Каждая категория становится отдельным уроком, порядок уроков — порядок появления категорий.

### `format: "words"` — словарные уровни Oxford 3000

Источник — PDF с таблицей `☐ | слово | часть речи | перевод | пример`
(пример и его перевод идут в одной ячейке). Поля разбираются по положению колонок
на странице, а не по порядку текста: длинные ячейки переносятся и перемешиваются.
Для этого формата в конфиге обязательны `prefix` и `title`.

Колонки слова и перевода узкие, и длинное слово в них рвётся посреди себя:
`достопримечательность` приходит как `достопримечательнос` + `ть`. По разметке
такой разрыв не отличить от обычного переноса по пробелу — ширина строки у них
одинаковая, а `ice cream` и `per cent` честно состоят из двух слов. Поэтому
арбитром служит пример: это же слово стоит в нём целиком, и куски склеиваются,
только если склеенное сходится со словом из примера почти по всей длине.

Уроков столько, сколько нужно на все слова, а размер выравнивается: 872 слова — это
88 уроков по 9–10 слов, а не 87 по десять и огрызок из двух.

Темы словам взять неоткуда, поэтому уроки собираются сами. По алфавиту их не режут:
подряд идущие слова похожи друг на друга (`actor`, `actress`, `add`, `address`),
а похожие слова в одном уроке мешают друг другу запоминаться. Вместо этого слова
перемешиваются так, что в уроке оказываются разные части речи, а слова с общим
началом попадают в разные уроки. Раскладка зависит только от зерна, так что
пересборка данных не перемешивает ID и не ломает прогресс.
Нумерация ID своя внутри категории (`GET001…`, `TAKE001…`), поэтому префикс главы указывается
в конфиге полем `prefix` (`CV` у English Core Verbs, `PR` у English Prepositions). В префиксе
допустимо подчёркивание — оно нужно составным категориям (`PRE_IN_FRONT_OF001`). Размер урока
и число уроков не фиксированы, пример употребления показывается под переводом. Так устроены
главы «English Core Verbs» и «English Prepositions».

### `format: "verbs"` — неправильные глаголы

Источник — Word-файл: заголовки «Этап N — …» и под каждым таблица
`№ | V1 | V2 — Past Simple | V3 — Past Participle | Перевод`. В конфиге обязательны
`prefix` и `title`.

Порядок источника сохраняется: глаголы в нём идут по убыванию полезности,
и перемешивать их, как слова в словаре, нельзя. Этап режется на уроки по десять,
размер выравнивается (22 глагола — это 8, 7 и 7), а номер этапа остаётся в названии
урока: «Этап 3 · глаголы 1–9».

У глагола вместо примера хранятся вторая и третья формы. Слэш в источнике означает
допустимые варианты (`got/gotten`), и при проверке принимается и запись целиком,
и каждый вариант по отдельности.

### Проверка

Скрипт остановится и ничего не запишет, если найдёт ошибку: неверный формат или порядок ID,
повторяющийся ID, пустое поле, а для глав с фразами ещё и не 20 уроков или не 10 фраз в уроке.
Предупреждения (одинаковые переводы, повтор фраз между главами, урок короче пяти записей)
запись не блокируют.

## Прогресс

Хранится в `localStorage` этого браузера, на сервер ничего не уходит.

| Ключ | Что внутри |
|---|---|
| `english-phrases:progress` | перерыв, коэффициент лёгкости и срок повторения каждой фразы, дни занятий |
| `english-phrases:theme` | светлая, тёмная или как в системе |
| `english-phrases:speech` | включена ли автоозвучка карточек |
| `english-phrases:session-size` | сколько записей брать за одно занятие |
| `english-phrases:daily-new` | предел новых фраз в день |
| `english-phrases:stages` | какие этапы проходить в занятии |
| `english-phrases:voice` | выбранный голос озвучки |
| `english-phrases:rate` | скорость речи |

Интервальное повторение по SM-2 — тому же алгоритму, что в Anki (`src/utils/sm2.ts`).
У каждой фразы свой перерыв и свой коэффициент лёгкости, он же скорость роста перерыва.
Расписание меняется один раз за занятие, по итогу всех этапов фразы.

Все ответы верные — перерыв растёт: 2 дня, 6 дней, дальше умножается на коэффициент
(2 → 6 → 15 → 38 → 95 дней и так далее). Ошибка возвращает фразу к двум дням и снижает
коэффициент на 0,32, не ниже 1,3: трудная фраза и потом будет расти медленнее лёгкой.

Ничего не возвращается на следующий день, даже только что заваленное: повторять то, что
видел вчера, бессмысленно — оно ещё не успело забыться. Фраза считается выученной
с перерыва от трёх недель.

Прогресс с прежних коробок Лейтнера переносится при первом открытии: коробка становится
соразмерным перерывом, а накопленные ошибки — пониженным коэффициентом.

Прогресс привязан к браузеру: очистка данных сайта или переход на другое устройство его сотрёт.
В настройках есть «Сохранить копию» и «Восстановить из файла».

## Офлайн и установка на телефон

Собранная версия — PWA: `vite-plugin-pwa` кладёт в кэш страницу, код, шрифты и все главы
(около 950 КБ), поэтому после первого открытия приложение работает без сети.

Про обновление приложение спрашивает: когда выходит новая версия, сверху появляется полоска
с кнопкой «Обновить». Молча подменять нельзя — приложение показывает то, что в кэше, и правки
иначе появлялись бы только со второго запуска, без всякого объяснения.

Проверить, что в кэш попало всё нужное:

```bash
yarn build && yarn pwa:check
```

Установка на телефон: открыть сайт в браузере и выбрать «Установить приложение»
(Android) или «На экран «Домой»» (iOS, Safari).

## Тесты

Логика проверяется без браузера, компоненты — в happy-dom. Весь набор проходит за пару секунд.

```bash
yarn test
```

| Что проверяется | Где |
|---|---|
| Перерывы и сроки SM-2 | `src/utils/sm2.test.ts` |
| Даты, переход через месяц и год, местное время | `src/utils/date.test.ts` |
| Сравнение ответа: регистр, апостроф, знак в конце | `src/utils/answer.test.ts` |
| Сбор занятия, подбор вариантов, повтор ошибок | `src/utils/practice.test.ts` |
| Итог занятия по фразе | `src/utils/session.test.ts` |
| Поиск, подсветка, склонение | `src/utils/search.test.ts` |
| Прогресс, серия дней, копия и импорт | `src/stores/progress.test.ts` |
| Проверка данных глав | `scripts/lib/validate.test.mjs` |
| Раскладка слов по урокам | `scripts/lib/words-pdf.test.mjs` |
| Этапы и формы неправильных глаголов | `scripts/lib/verbs-docx.test.mjs` |
| Упражнения и ход занятия | `src/components/**/*.test.ts` |

Тесты писались от уже случившихся поломок: двух верных вариантов на экране,
неугадываемого ответа при одинаковом переводе и потери прогресса из-за одного поля.
Каждая из них ловится соответствующим тестом.

## Структура

```
content/
  source/                 источники данных: Word-файлы глав и PDF словарных уровней
  chapters.config.json    порядок глав, id, формат источника, переопределение названий
scripts/
  build-data.mjs          источники → JSON
  lib/words-pdf.mjs       разбор PDF со словами и раскладка их по урокам
  lib/verbs-docx.mjs      разбор Word с неправильными глаголами по этапам
  validate-data.mjs       проверка public/data
  lib/validate.mjs        общие правила проверки
public/data/
  chapters.json           список глав
  chapters/*.json         главы с уроками и фразами
src/
  types/                  типы данных
  services/               загрузка JSON
  stores/                 Pinia: контент, настройки, прогресс
  composables/            переиспользуемая логика
  components/             компоненты интерфейса
    practice/             карточка, четыре упражнения, кнопка озвучки
  views/                  экраны
  router/                 маршруты (hash-режим)
  styles/                 Tailwind и цвета светлой и тёмной темы
```

## Примечание

`yarn audit` показывает одно предупреждение в зависимостях `mammoth` (`sprintf-js`). Пакет
используется только локально в скрипте конвертации ваших Word-файлов и в приложение не попадает:
`yarn audit --groups dependencies` на зависимостях приложения не находит ничего.
