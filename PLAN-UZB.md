# Узбекский язык: план работы

Решено: **не отдельный проект, а выбор языка в этом же**. Русский остаётся
по умолчанию, узбекский добавляется рядом.

Почему так: перевод 13 918 строк данных нужен при любом подходе — это 85% работы.
Разница только в коде. Два проекта означали бы каждую будущую правку делать дважды;
один проект стоит дороже вперёд и дешевле всегда потом.

Проверено до начала: второй язык в тех же файлах данных добавит **+530 КБ** (2 476 → ~3 007 КБ).
Узбекская латиница в UTF-8 занимает байт на букву вместо двух у кириллицы,
поэтому отдельные файлы под языки и возня с офлайн-кэшем не нужны.

## Устройство

**Словарь по русскому тексту.** Ключ — та самая русская строка, что в шаблоне:

```vue
{{ t('Пора повторить') }}
```

а в `src/i18n/uz.ts`: `'Пора повторить': 'Takrorlash vaqti'`. Ключи выдумывать не надо,
в шаблоне видно, что там будет написано, а без перевода остаётся русский —
экран не ломается, и пропуск находит проверка.

**Склонение языковое.** В русском три формы (`1 фраза` / `2 фразы` / `5 фраз`),
в узбекском согласования по числу нет вовсе: `5 ta ibora` при любом числе.

**Файлы:**

| | |
|---|---|
| `src/i18n/core.ts` | чистые функции: `translate`, `pluralize`, `nounOf` |
| `src/i18n/useI18n.ts` | композабл `{ t, plural }`, читает язык из настроек |
| `src/i18n/ru.ts` | три формы каждого существительного |
| `src/i18n/uz.ts` | узбекские слова и словарь интерфейса |

Язык живёт в настройках (`english-phrases:language`), по умолчанию `ru`.
При смене обновляется и `<html lang>` — он нужен для чтения вслух и переносов.

## Этапы

### ✅ Шаг 1. Механизм — сделано

Язык в настройках, модуль `i18n`, склонение переведено на языковое,
девять экранов переключены с `utils/plural` на `useI18n`, узбекский апостроф `ʻ`
добавлен в поиск (иначе `lugʻat` не найдётся по `lug'at`).

Внешне ничего не изменилось: русская версия работает как прежде.

### Шаг 2. Интерфейс

~360 строк обернуть в `t()` и перевести. По экранам:
главная → главы → урок → занятие → повторение → словарь → статистика → настройки.

В конце — переключатель языка в настройках и тест: у каждого `t('…')` есть перевод.

### Шаг 3. Механизм перевода данных

Данные собираются из `.docx` и `.pdf`. Переводить готовый JSON нельзя —
пересборка затрёт. Поэтому перевод кладётся отдельно, как уже сделано со вторыми примерами:

```
content/translations/<глава>.json
```

Одна запись на фразу: ключ (английский + часть речи + русский), узбекский перевод
и узбекские переводы её примеров. Сборка кладёт рядом с `ru` поле `uz`.

Проверки заодно: все ли записи переведены, нет ли кириллицы в узбекском,
не совпал ли перевод с русским дословно.

### Шаг 4. Данные по главам

От нужного к редкому: Everyday English, Small Talk, Useful Expressions →
остальные главы фраз → Core Verbs, Prepositions, Irregular Verbs → Oxford A1…B2.

Каждая глава отправляется отдельно, чтобы можно было смотреть по ходу.

### Шаг 5. Сверка

Тесты, сборка, проверка данных, офлайн-кэш, живой сайт.
